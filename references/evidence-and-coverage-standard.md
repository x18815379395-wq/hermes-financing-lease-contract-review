# 证据、阅读覆盖与核验规范

## 一、证据标签

| 标签 | 定义 | 可承担的证明范围 |
|---|---|---|
| `[用户提供]` | 合同、附件、企业说明、原始业务资料 | 证明文件内容或企业主张，不自动证明真实性 |
| `[官方法源]` | 全国人大、国务院、最高法、监管机关现行文本 | 证明现行规范内容和时效 |
| `[司法/监管记录]` | 法院、执行、处罚、登记、公示 | 证明对应公开记录及其时点 |
| `[第三方数据库]` | 企查查等商业数据库 | 检索、分诊和交叉验证，不替代官方原文 |
| `[联网线索—需复核]` | 媒体、网页、搜索摘要 | 定位线索，不单独承担重大结论 |
| `[合理推断]` | 基于已核实事实形成的判断 | 必须展示推导链和不确定性 |
| `[待核实]` | 缺证、冲突或覆盖不足 | 不能作为无条件审批依据 |

规则：

1. OCR只作为提取手段，关键金额、日期、序列号、条款号和签章须回看原图。
2. 只读部分页面时，结论标题须写“限定审查”。

4. 同名文件须记录哈希或修改日期，避免混用版本。

必须注意：

- 个保法第55条要求事前评估并对处理情况进行记录；

- 征求意见稿、会议纪要、司法政策与正式生效司法解释分开标注；
- 任何标为“法条原文”的引文必须逐字核对。

## 四、风险发现格式

每项发现按以下顺序：

1. **事实/条款**：精确引文、文件、条款号、页码；
2. **来源等级**：使用标准标签；
3. **判断**：事实、规则和推断分开；
4. **影响**：效力、权属、现金流、担保、执行或操作影响；
5. **缓释**：修订、补件、登记、保险、核验或结构调整；
6. **责任人和期限**：谁在何时完成；
7. **审批闸门**：是否未满足不得签署/放款。

## 五、复核门

正式交付前确认：

- 重大结论至少有一项一级来源或原始文件；
- 冲突事实未被静默择一；
- 计算均有工具输出和原始口径；
- 法条为现行版本且引用逐字；
- 敏感资料未未经授权上传或发送；
- 审查限制、缺失材料和人工判断点全部可见。
